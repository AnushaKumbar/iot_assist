# IoT Assist

Smart IoT device troubleshooting chatbot.

## Overview

IoT Assist helps users diagnose and resolve common smart device problems through an interactive chatbot. It provides troubleshooting guidance, device information, knowledge-base access, and conversation history.

## Features

- Interactive IoT troubleshooting chatbot
- Device dashboard and device status overview
- Knowledge base for common issues
- Troubleshooting workflows
- Chat history
- Settings management
- Responsive web interface

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm
